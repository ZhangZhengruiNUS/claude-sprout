- Agent Desktop Companion is a public GitHub repository currently still hosted at https://github.com/ZhangZhengruiNUS/claude-sprout; the remote has not been renamed yet.

## Important Decisions

- Agent Desktop Companion is the product/repository-facing name; Glint is the built-in pet and visual mascot, not the repository name.
- Do not make the product a browser-style dashboard. The Glint pet window is the first-class UI.
- Do not auto-approve Claude Code permission prompts.
- Keep prompts/outputs out of stored state by default. Conversation preview remains explicit local opt-in and stores only one bounded snippet.
- PowerShell hook writer is the default for Windows; Node hook writer remains a fallback.
- Default local data root is %USERPROFILE%\.agent-desktop-companion. AGENT_DESKTOP_COMPANION_HOME overrides it; CLAUDE_SPROUT_HOME and %USERPROFILE%\.claude-sprout remain legacy compatibility paths and are not moved or deleted automatically.
- Canonical hook scripts use agent-desktop-companion-* names; claude-sprout-* wrappers remain temporarily for compatibility.
- Codex-compatible imported pets use the Codex/Hatch Pet 8-column by 9-row atlas contract; unused cells remain transparent and should not be stepped through during playback.
- Imported pet deletion must stay explicit and local: removing from the app hides only the installed manifest, while deleting files removes only the validated imported pet directory under the active app-data pets root.
- User-facing pet assistant modes are Message and Board: Message is low-frequency rich-context intervention for permission/completion/failure, Board is the persistent multi-session stack, and waiting_input remains a weak non-interrupting state.
- Official Windows release artifacts are the standalone release exe and NSIS installer; MSI remains an optional maintainer build, not a required release artifact.
