## Current State

- Claude Sprout is a public GitHub repository at https://github.com/ZhangZhengruiNUS/claude-sprout.
- The app is a Tauri v2 + React + TypeScript + Rust desktop companion for Claude Code.
- The primary surface is a transparent, frameless, always-on-top pet window. The full session panel is secondary and opens from the pet or tray.

## Important Decisions

- Do not make the product a browser-style dashboard. The pet window is the first-class UI.
- Do not auto-approve Claude Code permission prompts.
- Keep prompts/outputs out of stored state by default.
- PowerShell hook writer is the default for Windows; Node hook writer remains a fallback.
- Imported Codex-compatible pet assets are copied into Claude Sprout app data; do not reference or distribute official Codex assets.
